## 2. 考證方法

寫入每條成語前，先確認「成語 → 古籍 → 典故」三者對應，再改寫成香港學生易明的繁中釋義。

使用工具與流程：

1. **`web_search`**：搜尋「成語＋出處＋書名」及教育部《成語典》條目，取得權威網址（教育部成語典、漢典、ctext、維基文庫等）。
2. **`web_fetch`**：直接抓取教育部《成語典》條目（例如「春暖花開」「花好月圓」「鳥語花香」）及漢典條目，核對釋義與書證。
3. **批次抓取核對**：以 HTTP 抓取漢典成語頁 `https://zdic.net/hant/<成語>`，程式抽取「拼音」與「出處」欄位，與本庫 488 條逐條比對（見 §3；比對腳本與批次檔只放 `/tmp`，不入 repo）。
4. **原文覆核**：疑難處再對照中國哲學書電子化計劃（ctext.org）及維基文庫原文。

考證原則：

1. **準確第一**：只引真實存在的古籍與篇名；沒有把握就改選其他成語，不憑空作故事。
2. `sourceBook` 採《書名·篇名》格式；成語見於文集所收篇目時，寫《文集名·篇名》（如《昌黎先生集·進學解》）。
3. `origin` 全部自行改寫，只引用古籍短句（屬公有領域），不抄現代辭書或網站的版權內容。
4. 同一成語有多個出處時，取較早或最直接出現該成語者，並在 `origin` 交代典故。
5. 釋義 15–60 個漢字、出處說明 15–90 個漢字，繁體中文、香港用語。

粵拼（Issue #1）另以 `to-jyutping@3.1.1` 產生基線，再逐條對照香港中文大學《粵語審音配詞字庫》「讀音＋詞例」、粵語辭叢（彙集粵典／維基辭典）及 rime-cantonese 字表校訂，詳見 §11。

- **拼音核對**：8 條與漢典標音不同，逐一覆核後：
  - 保留本庫標音（7 條）：約法三章 `yuē`（教育部標準）、欲速不達／四體不勤「不」標本調 `bù`（不採輕讀變調）、投閒置散 `sǎn`（依教育部《成語典》ㄙㄢˇ）、自強不息 `xī`（漢典 `xí` 為誤）、螓首蛾眉 `é`（漢典 `ér` 為誤）、為淵驅魚 `wèi`（介詞「為」讀去聲）。
  - 修正（1 條）：落英繽紛 由輸入錯字 `lùo` 改為 `luò`。
- **出處核對**：111 條與漢典所引書名不完全相同，逐一覆核後：
  - 110 條屬版本／別名／收錄差異而非錯誤，例如《易經》＝《周易》、韓愈《進學解》收入《昌黎先生集》、李白《長干行》收入《李太白集》、宋玉《對楚王問》收入《文選》、陶潛即陶淵明、《古今小說》即《喻世明言》、李愿（人名）與漢典誤植「李願」。

## 7. 全庫統計

- 成語 488 條；漢字全部為繁體（驗證腳本內建簡體／異體用字黑名單）。
- `meaning` 15–33 個漢字（契約 15–60）；`origin` 15–90 個漢字。
- 分類標籤 31 種，最常用：做事 103、情感 98、人物 89、社會 82、品格 66、學習 56、說話 54、自然 52、生活 51、思維 49、寓言 46、歷史 40、動物 29、藝術 25、堅持 20。
- 接龍連通性：**174 條**成語可接龍（尾字＝另一成語首字）、**578** 條接龍鏈接、341 條成語參與接龍；首字共 291 種、尾字共 374 種；最長接龍（估算）37 步。
- 常用連接字 49/49 兩端齊備：一、不、人、心、天、大、小、山、水、風、日、月、目、口、手、足、馬、龍、虎、金、玉、正、堂、行、里、中、上、下、有、無、生、死、成、明、清、花、春、秋、雲、海、火、石、書、言、語、事、理、道、德。
- 接龍設計的兩個已知例外（驗證腳本已按此設定）：
  1. 「不」「小」在四字成語中幾乎不作尾字（本庫收錄範圍內沒有），故只要求有以它們開頭的成語，用於接龍起首。
  2. 「里」與「裡」視為等價（例：一日千里 → 裡應外合），因繁體標準寫法為「裡」。

## 9. 限制與備註

- 古籍版本眾多，同一成語可能有更早用例；本庫採「最常見且可考的典故來源」，`origin` 說明故事，不宣稱唯一出處。
- 9 條 `sourceBook` 未細分篇名（見 §3），因該語在該書中難以定位單篇，屬可接受的 warning。
- 4 條漢典未收，已用教育部《成語典》、ctext、維基文庫等核對（§5）。
- 資料以 `/tmp/idioms-batch-*.json` 分批撰寫、以 Node 腳本合併成 `src/data/idioms.json`；repo 只保留最終 JSON，不保留批次檔。
- 更新資料後必須重跑 `node scripts/verify-idioms.mjs`；任何欄位或接龍規則改動需同步更新本文件及驗證腳本。

## 11. 粵拼（Jyutping）資料（Issue #1：同時提供廣東話與普通話拼音）

### 11.1 方法

1. **基線自動轉換**：以 CanCLID `to-jyutping@3.1.1` 將 488 條成語逐條轉換為粵拼（Lead 提供 `/tmp` 基線檔）。轉換工具只在開發期使用，**不會加入 repo 的 npm 依賴**。
2. **逐條覆核 488/488**：
   - 抓取香港中文大學《粵語審音配詞字庫》887 個用字的讀音與「詞例」，程式自動比對每條成語是否出現於某讀音的詞例（例：「嘔心瀝血」列於「瀝 lik6」詞例、「敬而遠之」列於「遠 jyun6」詞例）。
   - 對照「粵語辭叢」（jyutjyu.com，彙集粵典 words.hk 與維基辭典讀音）核對有條目的成語（155 條）。
   - 對照 rime-cantonese 字表與 to-jyutping 候選讀音，審核：音節是否在該字讀音表內、有否誤選罕用／廢棄讀音、工具選了非預設讀音的位置，以及 60 個真多義字（上、生、為、行、長、重、樂、數、中、興、應、相、看、勝、見、車、玉、朝、易…）在成語語境的取捨。
3. **採成語語境讀音**（非單字預設）：例如「葉公好龍」好 = hou3（喜愛）、「敬而遠之」遠 = jyun6（遠離）、「天衣無縫」縫 = fung6（縫隙）、「出奇制勝」勝 = sing3（勝利）、「不亦樂乎」樂 = lok6（快樂）。
4. 全部 488 條以 `node scripts/verify-idioms.mjs` 驗證（存在、4 音節、`^[a-z]+[1-6]$`、對應 4 字）。

### 11.4 詞典分歧與取捨

粵語存在文白異讀，不同詞典對個別成語的標音未完全一致。本庫探討後按「香港通行成語讀音」取捨，並在此記錄：

- **車水馬龍**：粵典／rime 列 geoi1（文讀）、ce1（口語）；依 Issue 審核意見及通行讀法採 `ce1`。
- **坐井觀天**：審音字庫／粵典標 zo6（文讀）；依 Issue 審核意見採通行口語 `co5`。
- **後生可畏**：多數詞典標 sang1（文讀）；「後生」作「年輕人」解時讀 `saang1`（依 Issue 審核意見）。
- **圖窮匕見**：見＝現，粵語辭叢／維基辭典標 `jin6`（部分人口語讀 gin3，本庫採 jin6）。
- **咄咄逼人**：審音字庫詞例作 deot1，粵典作 cyut3（亦收 deot1）；本庫採 `deot1`。

### 11.5 統計

- 粵拼覆蓋：**488/488** 條；全部 4 音節、每節符合 `^[a-z]+[1-6]$`。
- 與粵語辭叢有讀音的 155 條比對：**143 條完全一致**；12 條差異逐一覆核（6 條為其他詞典／OCR 的非標準羅馬字或異體，6 條屬文白／異讀取捨，見 §11.4）。
- 驗證結果：`node scripts/verify-idioms.mjs` → **PASS**（原有資料契約＋粵拼檢查）。

### 11.6 限制

- 粵拼為靜態文字資料，遊戲暫未接粵語語音朗讀。
- 少數成語在粵語詞典間沒有唯一讀音；本庫已記錄取捨（§11.4），如日後有更權威共識可更新。
- 粵拼一律標本調，不標連讀變調（與粵拼輸入法及字典慣例一致）。
- 更新成語資料時必須同步更新 `cantonese` 欄位並重跑 `node scripts/verify-idioms.mjs`。
